# ScriptShade Website


## Files
- `index.html` — page structure/content
- `style.css` — styling and responsive layout
- `script.js` — lightweight scroll animations
- `assets/` — uploaded ScriptShade showcase images

## Deploy
Upload these files to the root of your GitHub Pages repository, then enable Pages from the repository's Settings > Pages.

Before publishing, replace the `href="#"` download/GitHub/Discord links in `index.html` with your real links.
